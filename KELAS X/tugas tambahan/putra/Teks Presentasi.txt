SLIDE 3 - TEKSTAK (TECHNOLOGY STACK)
========================================

Untuk merealisasikan proyek ini, saya mengkombinasikan beberapa teknologi 
yang handal:

BACKEND (Sisi Server):
- Laravel 11 — Framework PHP andalan untuk menyajikan REST API.
- Laravel Sanctum — Menangani urusan login dan autentikasi via token.
- SQLite — Solusi database yang praktis dan efisien untuk menyimpan data.
- Eloquent ORM — Memudahkan saya dalam berinteraksi dengan tabel database.

FRONTEND (Sisi Klien):
- React.js 18 — Library JavaScript populer untuk merancang User Interface.
- React Router DOM — Mengatur perpindahan halaman secara dinamis (SPA).
- Framer Motion — Memberikan sentuhan animasi dan transisi yang memukau.
- Lucide React — Kumpulan ikon berdesain minimalis dan modern.
- Vite — Engine untuk proses build yang sangat responsif dan cepat.

ARSITEKTUR:
- Sistem Frontend dan Backend berdiri sendiri-sendiri (decoupled).
- Pertukaran data dijembatani oleh REST API.
- Secara default, Frontend berjalan di port 5173 dan Backend di port 8000.

SLIDE 6 - DAFTAR ENDPOINT API
========================================

Backend Laravel menyediakan rute-rute berikut untuk diakses:

JALUR UMUM (Tidak Perlu Login):
- POST   /api/register     --> Mendaftarkan admin baru
- POST   /api/login        --> Mengautentikasi dan merilis token
- GET    /api/projects     --> Meminta sekumpulan data proyek
- GET    /api/skills       --> Meminta daftar keahlian
- POST   /api/contacts     --> Mengirimkan pesan baru

JALUR KHUSUS (Wajib Bearer Token):
- GET    /api/me           --> Memeriksa informasi pengguna aktif
- POST   /api/logout       --> Menghancurkan token dan keluar sesi
- GET    /api/contacts     --> Mengambil semua pesan masuk untuk dibaca admin

SLIDE 8 - ASPEK KEAMANAN
========================================

Meski sederhana, keamanan tetap menjadi prioritas:

1. AUTENTIKASI BERBASIS TOKEN
   - Sanctum memfasilitasi penerbitan Token Akses Personal.
   - Rute-rute rahasia mensyaratkan token ini disisipkan pada Authorization header.

2. ENKRIPSI KATA SANDI
   - Semua kata sandi diacak oleh algoritma bcrypt. Database sama sekali 
     tidak menyimpan kata sandi dalam bentuk teks asli.

3. PEMBATASAN HALAMAN
   - Akses ke Dashboard diproteksi ketat.
   - Pengunjung yang belum login akan langsung dilempar kembali ke halaman Login.

4. FILTERING INPUT
   - Pemeriksaan data berlapis ganda; mulai dari peringatan di browser (frontend) 
     hingga validasi solid di tingkat server (backend).

5. PENCABUTAN TOKEN
   - Saat proses otentikasi baru, token lama otomatis hangus guna meminimalisir 
     resiko pembajakan sesi.


========================================
SLIDE 9 - KENDALA & PEMECAHAN MASALAH
========================================

Dalam proses pengerjaannya, saya menemui beberapa rintangan:

1. INTEGRASI DUA DUNIA
   Kendala: Laravel (port 8000) menolak permintaan dari React (port 5173) 
   karena perlindungan CORS.
   Solusi: Melakukan penyesuaian di pengaturan CORS Laravel agar mengizinkan 
   koneksi dari domain frontend.

2. PENGELOLAAN STATUS LOGIN
   Kendala: Bagaimana memastikan komponen manapun tahu apakah user sudah login?
   Solusi: Mengimplementasikan Context API bawaan React untuk menyebarkan 
   data user dan token ke seluruh penjuru aplikasi.

3. MENGANTISIPASI API DOWN
   Kendala: Jika backend mati atau database kosong, tampilan web bisa hancur.
   Solusi: Menyiapkan data dumi (dummy data) yang otomatis tayang sebagai 
   pengganti ketika API gagal memberikan respons yang diharapkan.
